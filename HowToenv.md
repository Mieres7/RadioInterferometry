Acción,Comando
Crear entorno manual: micromamba create -n mi_entorno python=3.11
Activar entorno: micromamba activate mi_entorno
Ver entornos creados: micromamba env list
Desactivar entorno: micromamba deactivate
Eliminar entorno: micromamba env remove -n mi_entorno
Limpiar caché: micromamba clean --all
